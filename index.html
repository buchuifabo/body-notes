餐后的小习惯

01 / 轻松走动舒适时慢走10—15分钟，不必快走。

02 / 留出消化时间避免刚吃饱就高强度运动，按餐量与胃肠舒适度安排。

03 / 留意反流有夜间反流者，晚餐与躺卧、入睡至少间隔3小时。

04 / 正常饮水不必靠浓茶、醋或所谓排毒饮品消食。

CHAPTER 04 / MOVE FOR THE LONG RUN

为未来，保留行动力。

不是把运动做满，而是持续给身体适合的刺激。

30岁不是训练的截止日期。

肌肉与力量、骨强度、心肺适能、平衡与关节活动能力，都值得长期维护。训练、足够营养与恢复一起发挥作用。

本周记录勾选表示本周已练过，不能代替完整的训练量记录。
一般成人：每周至少2天力量训练，累计150—300分钟中等强度有氧。初学者从少量开始。骨质疏松、持续关节痛或明显活动受限时需调整动作；胸痛、晕厥等异常应停止运动并就医。
