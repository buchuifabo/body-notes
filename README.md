# 身体笔记 / Body Field Notes

可编辑的中文营养与运动笔记网页，保留铅笔素描图谱。

## 功能

- 人体结构与四张原始素描科普图。
- 可编辑营养分类、食物来源和说明，支持搜索。
- 根据身体资料与活动系数估算热量，切换维持或增肌目标。
- 编辑三餐时间、比例与菜单，自动计算三餐热量预算。
- 编辑运动计划，勾选本周练习并记录身体反馈。
- 浏览器自动保存、JSON备份导入导出、打印为PDF。

## 本地使用

这是无构建步骤的静态网站，没有必须安装的依赖。

```bash
python -m http.server 8000
```

打开 `http://localhost:8000`。也可用任意静态网站服务器。

## 修改

- `index.html`：页面结构。
- `style.css`：排版、配色、响应式与打印样式。
- `app.js`：初始资料、笔记内容、计算和保存逻辑。
- `assets/`：四张原始素描图谱。

初始笔记在 `app.js` 的 `DEFAULT` 中。网页编辑内容保存在当前浏览器的 localStorage，不会自动提交到Git，也不会跨设备同步。可导出JSON后在另一设备导入。修改源码中的默认内容不会覆盖已有浏览器笔记。

## 使用范围

当前提供一般成人的科普与计划工具。预置身体资料与菜单是计算示例；每个人应按自己的情况调整。热量预算不是菜单的精确热量，修改预算不会自动换算食材克数。特殊疾病、孕哺期或医嘱限制需另行评估。

网页内列有WHO、NIH相关研究与Harvard Nutrition Source的参考链接。原始图谱的文字不会随网页编辑改变。
